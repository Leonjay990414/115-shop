本手冊為「智光商工 115 校慶客製化商品調度管理後台 (Admin Panel)」之內部標準作業程序 (SOP)。
系統落實「嚴格順序相依有限狀態機 (State Machine)」、「角色職責脫敏與權限控制 (RBAC)」以及「實體紙本三聯單零跑版列印標準」，所有幹部請嚴格遵照本手冊執行業務。

--------------------------------------------------------------------------------
【第一章、後台雙軌登入系統與帳號啟用生命週期】
--------------------------------------------------------------------------------
系統配置 17 位專案成員席位（涵蓋指導老師、科主任、總召、美術組、外送組、財務組、產線製作組等），並實施雙軌安全登入：

一、 分頁一【帳號密碼登入 (首次啟用開通)】：
1. 初始狀態：系統中所有 17 位成員在建立時，開通狀態預設為 `isActivated = false`。
2. 首次開通：成員必須在登入介面選擇「分頁一：帳號密碼登入」，輸入配發之幹部帳號與預設密碼。
3. 密碼登入成功後，資料庫將自動將該幹部之 `isActivated` 欄位更新為 `true`，正式完成席位啟用。

二、 分頁二【身分快捷驗證碼登入 (防呆保護機制)】：
1. 適用於日常快速登入：幹部於下拉選單選取自己的「身分角色席位」，並輸入「專屬數字驗證碼」。
2. 嚴格防呆阻擋邏輯：
   - 系統比對驗證碼前，會先行檢驗該身分是否已完成首次帳密登入啟用。
   - 若資料庫查出該身分尚未開通 (`isActivated !== true`)，系統將全面拒絕登入，並彈出警示視窗：
     「⚠️ 該身分尚未完成首次登入開通，請先切換至【帳號密碼】登入一次以啟用驗證碼功能！」
   - 若已開通且驗證碼正確，方可順利登入後台。

三、 總召專屬管理面板 (Staff Auth Management)：
1. 總召角色與系統管理員具有「幹部權限管理面板」之最高操作權限。
2. 總召可於面板內即時動態檢視 17 位成員之真實姓名、組別、系統帳號、登入密碼、專屬驗證碼以及「首次開通狀態 (isActivated)」。
3. 支援一鍵重設密碼、修改驗證碼或強制切換開通狀態，保障後台營運不中斷。

【第二章、順序相依業務狀態機 (State Machine) 嚴格操作流程】
--------------------------------------------------------------------------------
後台工單採用強制性單向解鎖狀態機，嚴禁越級或逆向操作，確保產線與金流零漏洞：

【階段一：美術組圖審 (QC Review)】
1. 初始狀態：顧客於前台下單後，訂單工單預設狀態為「待審核」。
2. 功能鎖定防呆：此時「列印三聯單」按鈕一律保持 disabled 鎖定狀態，且「外送組」、「財務組」、「產線組」狀態下拉選單全面反灰禁改。若點擊列印按鈕，系統將提示：「⚠️ 必須等美術組審核通過後方可列印三聯單！」。
3. 審核操作：
   - 美術組人員檢視顧客圖檔尺寸、解析度（是否達標 1080P）與客製備註。
   - 若合規：點擊側邊抽屜之「✅ 圖審通過」按鈕，狀態變更為「審核通過」。
   - 若不合規：點擊「❌ 審核不通過」，必須填寫具體退件原因（如：圖檔嚴重模糊、內容缺損等），系統將記錄退件原因並推播至前台訂單查詢。顧客有 4 天時間修改補件，若第 5 天未補件將正式開立退貨憑證。

【階段二：解鎖三聯單列印與派送組外送 (Logistics)】
1. 解鎖條件：只有當美術組切換為「審核通過」時，系統才自動連鎖解鎖「🖨️ 列印三聯單」功能，並解鎖「外送派送組」狀態選單。
2. 列印防偽三聯單：
   - 幹部可於側邊抽屜單筆點擊「🖨️ 列印三聯單 (A4單頁)」，或在列表多選工單後點擊「批次列印 A4 三聯單」。
   - 列印視窗開啟並觸發 `window.onafterprint` 事件後，系統自動將資料庫訂單欄位更新為：
     `printStatus: 'PRINTED'`，並記錄 `printedAt` 時間戳記。
   - 介面標籤同步轉為綠色徽章「🟢 已列印 (PRINTED)」，嚴格防止重印或漏印。
3. 外送派送流轉：
   - 派送組將已列印之紙本三聯單送至訂購學生班級，狀態由「未派送」變更為「派送中」➔ 現場交件簽署後變更為「已派送完成」。

【階段三：解鎖財務組現場收款 (Finance)】
1. 解鎖條件：只有當派送組狀態切換為「已派送完成」時，系統才解鎖「財務組」狀態選單（未收款 / 待收款 / 已收款）。
2. 隨行收款原則：
   - 依校慶專案規範，派送組到班派單時，財務組人員必須「隨行前往」。
   - 現場向訂購同學點清現金款項，確認無誤後，於三聯單現場親筆簽名。
3. 系統核銷：財務幹部於後台將工單狀態切換為「已收款」或點擊「💵 財務收款核銷」按鈕，記錄收款時間與核銷幹部編號。

【階段四：解鎖產線組實體製作 (Production)】
1. 解鎖條件：只有當財務組狀態確實切換為「已收款」後，系統方可解鎖「產線製作組」狀態選單（未排單 / 製作中 / 已完成）。
2. 產線進度更新：
   - 收到收款確認後，產線組依防偽流水號工單調取原圖進行實體商品印製。
   - 狀態依序流轉：未排單 ➔ 製作中 ➔ 印製包裝完畢切換為「已完成」。

【階段五：總召審定與匯出總表】
1. 總召與科主任隨時抽查各軌進度，並可於訂單詳情進行「總召最終審定」。
2. 後台提供「一鍵匯出 Excel 總表」功能，內嵌原圖之 `=HYPERLINK()` 公式，便於總帳造冊存檔。

【第三章、A4 零跑版三聯單標準版型與簽名責任歸屬】
--------------------------------------------------------------------------------
三聯單為法律與校園行政核銷之唯一正式憑據，採嚴格 CSS `@media print` 規格，單頁精準容納三大聯（嚴禁跨頁），各聯職責與簽名配置如下：

一、 第一聯：【第一聯：顧客付款與取貨憑證聯】
- 備註說明：本聯交由顧客收執留存，憑此聯於校慶當日取貨時由攤位蓋章收回。
- 簽署欄位（三方）：
  1. 顧客確認簽名（顧客確認訂單品項與金額無誤）
  2. 財務實收簽署（隨行財務人員親筆簽名，證明現場已收訖現金）
  3. 【取件蓋章戳印處】（校慶取貨時由現場發貨幹部加蓋「已取貨訖」印章收回）

二、 第二聯：【第二聯：顧客收執留存聯】
- 備註說明：本聯由顧客永久留存存查，載明客製化商品權益與退貨規範。
- 簽署欄位（三方，嚴禁出現尚未製作的商品製作組簽名）：
  1. 顧客簽收簽名（確認收到單據與規範說明）
  2. 外送派送員簽署（派送至班級之幹部簽名）
  3. 隨行財務員簽署（現場隨行財務幹部簽名）

三、 第三聯：【第三聯：主辦方行政核銷與總召留存聯】
- 備註說明：現場收款簽署完成後，由外送派送組與財務組帶回資處科辦公室留存核銷。
- 簽署欄位（三方）：
  1. 財務入帳簽署（財務組點收帳目入庫簽署）
  2. 外送派送員簽署（證明單據已送達顧客並帶回）
  3. 總召最終審定（專案總召審核銷帳蓋章）

【第四章、後台【手動發信控制台】操作說明】
--------------------------------------------------------------------------------
為防止顧客填寫無效 Email、重覆扣信或誤發通知信，系統已將訂單確認信改為「後台手動核驗後發送」：

一、 操作步驟：
1. 幹部點擊任一訂單的「👁️ 詳情」按鈕，開啟側邊抽屜檢視視窗。
2. 視窗最頂部常駐【📋 顧客個資與圖檔審核區塊】：
   - 顯示目前發信狀態標籤（待審核發信 / 已核驗發信）。
   - 幹部核驗顧客姓名（是否為繁體中文）、班級、電話、Email 以及圖檔清晰度無誤。
3. 點擊按鈕：「📧 審核無誤，發送訂單確認信至顧客信箱」。
4. 系統彈出確認對話框，幹部確認後系統呼叫 Google Apps Script (GAS) API (`action: "send_order_success"`)。
5. 發送成功後：
   - 資料庫訂單自動更新欄位：`mailStatus: 'SENT'` 與 `mailSentAt: ISO`。
   - 按鈕即刻變為綠色 disabled 狀態：「✔ 訂單確認信已送達 (寄出時間)」。
   - 徹底杜絕重複誤寄，確保校慶客製化專案行政品質！
